# دليل قاعدة البيانات (DATABASE.md)

تعتمد قاعدة بيانات التطبيق على **مبدأ Offline-First**، وتُبنى على طبقتين:

## 1. قاعدة البيانات المحلية (IndexedDB)
نستخدم مكتبة `Dexie.js` للتعامل مع `IndexedDB`.
الجداول (Collections) الرئيسية المتاحة:
- `bookmarks`: يحفظ العلامات المرجعية (رقم السورة، الآية، التاريخ).
- `readingProgress`: يحفظ آخر آية قرأها المستخدم (لتحديث ميزة "آخر موضع قراءة").
- `notes`: يحفظ ملاحظات المستخدم حول آيات معينة.

**مزايا الاستخدام المحلي**:
- سرعة عالية جداً في القراءة والكتابة (Zero Latency).
- إمكانية العمل التام بدون إنترنت.

## 2. قاعدة البيانات السحابية (Supabase)
قاعدة البيانات السحابية تعمل كـ "نسخة احتياطية" وجسر لمزامنة البيانات بين الأجهزة المتعددة.
- يتم الاعتماد على تعريف الجداول بنفس الهيكلية (Schema) تقريباً.
- تحتوي الجداول على عمود `user_id` لربط البيانات بالمستخدم المسجل.

## التفاعل بين الطبقتين (Data Flow)
1. يقرأ التطبيق من IndexedDB.
2. عند التعديل، تُعدل البيانات في IndexedDB لضمان استجابة سريعة للواجهة.
3. يقوم محرك المزامنة (Sync Engine) بمحاولة رفع التغييرات إلى Supabase إذا كان هناك اتصال.
