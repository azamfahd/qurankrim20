# إعداد توقيع إصدار Android الدائم — أنيس القلوب

## الحالة

أُعدّ Workflow في `.github/workflows/build-apk.yml` لبناء APK من نوع Release فقط، واستعادة ملف المفتاح من GitHub Actions Secrets، والتحقق من أن شهادة APK تطابق المفتاح قبل رفعه. لا يوجد رجوع تلقائي إلى APK Debug. عند نجاح البناء على `main`، يُحدّث Workflow إصدار GitHub ذي الوسم `latest` ويرفع `public/version.json` إلى المستودع.

## الأسرار المطلوبة

من صفحة المستودع على GitHub افتح **Settings → Secrets and variables → Actions → New repository secret**، ثم أضف السرّين التاليين كما هما:

1. `ANIS_RELEASE_KEYSTORE_BASE64` — الصق قيمة Base64 كاملة من ملف الأسرار الخاص، دون اسم السر أو كلمة `Value:`.
2. `ANIS_RELEASE_STORE_PASSWORD` — الصق كلمة المرور كاملة من الملف نفسه.

اسم alias ليس سرًا؛ يستخدم Workflow القيمة الثابتة `anis_alqulub_release`. لا تضف ملف `.jks` أو `.keystore` إلى Git، ولا تضع كلمات المرور في ملفات المشروع أو الرسائل.

## ملفا المفتاح

- ملف قيم GitHub Secrets: `AnisAlQulub-Release-Secrets.txt` في المساحة الخاصة خارج المستودع.
- نسخة المفتاح الاحتياطية: `AnisAlQulub-Release-Key.jks` في المساحة الخاصة خارج المستودع.

احتفظ بنسختين احتياطيتين مشفرتين في مكانين آمنين. لا تغيّر المفتاح أو alias أو كلمة مروره بعد نشر أول APK بالمفتاح الجديد. بصمة SHA-256 لشهادة هذا المفتاح:

`02:92:D9:37:75:7B:D4:C3:31:A1:E7:C0:8C:FA:DD:E4:8F:63:A5:3A:E3:0E:55:CC:9A:BF:57:BF:1B:00:8A:2D`

## التحقق والنشر

1. أضف السرّين أعلاه إلى **المستودع `azamfahd/qurankrim20` نفسه**.
2. بعد وصول تغييرات إعداد التوقيع إلى `main`، شغّل **Actions → Build Android APK Automatically → Run workflow** واختر `main`، أو ارفع/ادمج تغييرًا إلى `main` بعد حفظ الأسرار.
3. يجب أن تنجح خطوات استعادة المفتاح، `assembleRelease`، والتحقق من الشهادة. يتوقف Workflow إذا غاب سر أو فشل التوقيع؛ لا ينشر Debug بدل Release.
4. افتح **Actions → Artifacts** وتحقق من وجود `AnisAlQulub-Android-APK`، ثم افتح [صفحة Releases](https://github.com/azamfahd/qurankrim20/releases) وتحقق من وجود `app-release.apk` تحت `latest`.
5. في سجل Actions يظهر ملخص بصمة الشهادة. يجب أن تطابق البصمة أعلاه.

كل تحديث يصل إلى `main` يشغّل البناء والنشر. رفع التغيير إلى فرع آخر لا ينشر APK للمستخدمين. رابط التحميل المستقر المُستخدم حاليًا هو `https://github.com/azamfahd/qurankrim20/releases/download/latest/app-release.apk`، وبيانات الإصدار في `public/version.json`.

## انتقال المستخدمين من التوقيع القديم

كان المفتاح السابق وبياناته ضمن تاريخ المستودع العام، ولذلك نعامله على أنه مكشوف ولا نستخدمه للإصدارات الجديدة. Android لا يسمح بتثبيت APK الموقّع بالمفتاح الجديد فوق نسخة مثبتة بالمفتاح القديم. قبل تثبيت أول APK بالمفتاح الجديد، خذ نسخة احتياطية مناسبة من بيانات المستخدم، ثم أزل النسخة القديمة وثبّت النسخة الجديدة مرة واحدة. بعد الانتقال، ستقبل الأجهزة التحديثات التي تُوقّع بالمفتاح الجديد نفسه.

إزالة المفتاح وكلمة مروره من أحدث commit لا تمحوهما من تاريخ Git القديم. محو التاريخ يتطلب إعادة كتابة الفروع والوسوم ودفعًا قسريًا، وقد يتطلب من كل المتعاونين إعادة استنساخ المستودع. لم تُنفّذ إعادة كتابة التاريخ ضمن هذا الإعداد.
