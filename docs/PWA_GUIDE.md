# دليل تطبيق الويب التقدمي (PWA_GUIDE.md)

تم تصميم هذا التطبيق ليكون PWA (Progressive Web App) حقيقي، مما يوفر تجربة شبيهة بالتطبيقات الأصلية مع التثبيت والعمل بدون إنترنت.

## المكونات الأساسية
1. **Service Worker (SW)**
   - نستخدم `vite-plugin-pwa` و `Workbox` لإنشاء الـ Service Worker.
   - مهمته اعتراض الطلبات الشبكية وتقديم الملفات المخزنة مسبقاً (Cache) عند انقطاع الإنترنت.
2. **Web App Manifest (`manifest.json` / `manifest.webmanifest`)**
   - يحتوي على معلومات التطبيق: الاسم، الأيقونات بجميع الأحجام، ألوان الثيم، ووضع العرض (Standalone).
   - هذا الملف مسؤول عن ظهور شاشة الترحيب (Splash Screen) وموجه التثبيت (Install Prompt).

## استراتيجية التخزين المؤقت (Caching Strategy)
- **ملفات الأصول (Static Assets)**: يتم تخزين الـ HTML, CSS, JS، والأيقونات الأساسية في الـ Cache تلقائياً عند أول زيارة.
- **ملفات الخطوط (Google Fonts)**: تخزن باستخدام استراتيجية `CacheFirst` لضمان عدم تحميلها مراراً وتكراراً.

## تحديث التطبيق
- عندما يتوفر إصدار جديد، يكتشف الـ Service Worker ذلك في الخلفية.
- قد تظهر رسالة للمستخدم تطلب منه التحديث (أو يتم التحديث التلقائي). بمجرد التحديث، يتم استبدال الملفات القديمة في الـ Cache.
