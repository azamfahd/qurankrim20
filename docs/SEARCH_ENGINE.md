# محرك البحث (SEARCH_ENGINE.md)

نظام البحث في التطبيق ينقسم إلى قسمين لتوفير أفضل تجربة:

## 1. محرك البحث المحلي السريع (Local Fast Search)
- يبحث داخل نصوص الآيات المحملة محلياً.
- **التطبيع (Normalization)**: يقوم بإزالة التشكيل (الفتحة، الكسرة، إلخ) والهمزات والألف الخنجرية لمطابقة النص المكتوب بالنص القرآني بدقة.
- **الأداء**: يتميز بسرعة استجابة لحظية، حيث أنه لا يتطلب أي استدعاء للشبكة.
- **Debounce**: يتم استخدام تقنية الـ Debounce لتأخير البحث بضع ملي ثوانٍ بعد توقف المستخدم عن الكتابة لمنع التشنج (Lag) أثناء الكتابة السريعة.

## 2. البحث الذكي (AI-Powered Semantic Search)
- يعتمد على تكامل مع Google Gemini API.
- يتيح للمستخدم كتابة أسئلة أو مفاهيم (مثال: "ما هي الآيات التي تتحدث عن الصبر؟").
- **القيود**: يتطلب اتصالاً بالإنترنت ووجود مفتاح واجهة برمجة تطبيقات (API Key) صالح.
- يتم إرسال الاستعلام للموديل الذي يحلل الطلب ويسترجع الآيات ذات الصلة بالسياق.

## التحسينات المستقبلية
- إضافة Indexing محلي لجميع آيات القرآن لتسريع البحث الأولي.
- دمج قواعد البحث المتقدم (Full-Text Search) لـ IndexedDB إذا لزم الأمر.
