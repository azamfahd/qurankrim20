# سجل التغييرات (CHANGELOG.md)

## [1.1.0] - 2026-08-01
### أُضيف (Added)
- ميزة البحث المتقدم الذكي المعتمد على الذكاء الاصطناعي (Gemini).
- نظام PWA المتكامل للعمل بدون إنترنت مع استراتيجية تخزين مؤقت متقدمة.
- ميزة التلاوات الصوتية مع إمكانية التنزيل والتشغيل بدون اتصال.
- المزامنة السحابية عبر Supabase للمستخدمين المسجلين.
- تقارير وملفات توثيق هندسية متكاملة للمشروع.

### عُدِّل (Changed)
- تم تحسين أداء البحث المحلي بإضافة Debounce وتطبيع النصوص.
- تعديل بنية المشروع لتعتمد بالكامل على IndexedDB للتخزين السريع.
- تحسين واجهة المستخدم وتجربة المستخدم (UI/UX) لدعم الشاشات بجميع أحجامها.

### أُصلح (Fixed)
- إصلاح مشاكل الـ Build الخاصة بـ Vite وإزالة إعدادات الخادم المخصص غير المطلوبة (server.ts).
- معالجة مشاكل PWA لضمان تسجيل Service Worker بنجاح.
- تحسين التعامل مع الأخطاء الناتجة عن اتصال الشبكة.
